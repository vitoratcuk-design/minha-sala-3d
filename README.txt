NEXUS v0.5 — Escritório 3D, Muu, Caco e Shark

Abra index.html no Google Chrome com internet. Mantenha todos os arquivos na mesma pasta.

Melhorias v0.5:
- Câmera isométrica mais próxima; luzes quentes, detalhes no piso, prateleiras, plantas, telas com gráficos ilustrativos e área de café.
- Caco: painel com resumo das despesas por categoria, além de movimentações e metas já existentes.
- Shark: painel de prioridades, alerta para tarefas atrasadas e cronômetro local de foco de 25 minutos.
- Muu: preservado, com diário, academia e calculadora de risco demonstrativos.

IMPORTANTE:
- Chat dos agentes é DEMONSTRATIVO; ainda não usa IA real.
- Gráficos das telas 3D são ILUSTRATIVOS, não cotações.
- Dados são salvos localmente neste navegador. Faça backup pela aba Dados de cada agente antes de mudar de computador ou limpar o navegador.
- Esta atualização não altera os nomes das chaves de armazenamento v0.4 e v0.3 para preservar registros no mesmo navegador/origem. Porém, abrir um arquivo local em caminhos diferentes pode criar armazenamento distinto no Chrome. Exporte os dados primeiro.
- Para ver alterações, feche a versão antiga, extraia esta pasta e abra o novo index.html. Não há atualização automática de arquivos locais.
